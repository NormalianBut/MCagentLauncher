# License Draft

This file records the current license direction for MCagentlauncher. It is not the final license decision.

## Current Preference

- Desktop App: GPL-3.0-or-later is preferred.
- MCAgent Server: AGPL-3.0-or-later is preferred.
- Schema / Protocol: MIT or CC0 is preferred, pending community ADR confirmation.
- Rules / Dataset / Models: to be discussed separately because reuse, attribution, privacy, and community governance requirements may differ.

## Notes

The final license structure should be decided through an ADR before the first public stable release. Contributors should avoid adding code, data, or model artifacts with incompatible licenses until the licensing decision is complete.
