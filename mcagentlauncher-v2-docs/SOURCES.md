# Sources

用于确认平台职责的官方资料：

1. GitHub Actions 文档说明 workflow 可由 GitHub 活动、定时任务或外部事件触发：  
   https://docs.github.com/actions/using-workflows/events-that-trigger-workflows

2. Vercel Git 文档说明 Git 集成可为 push 生成 Preview Deployment，并从 production branch 生成 Production Deployment：  
   https://vercel.com/docs/git

3. Vercel for GitHub 文档说明 Vercel 可自动部署 GitHub 项目并提供 Preview Deployment URL：  
   https://vercel.com/docs/git/vercel-for-github

4. Supabase 本地开发文档说明 Supabase CLI 可用于本地开发与项目管理：  
   https://supabase.com/docs/guides/local-development

5. Supabase CLI 文档说明 CLI 可用于本地开发并部署到 Supabase 平台：  
   https://supabase.com/docs/reference/cli/introduction

6. Supabase Edge Functions 文档说明 Edge Functions 是全球分布的服务端 TypeScript 函数：  
   https://supabase.com/docs/guides/functions
