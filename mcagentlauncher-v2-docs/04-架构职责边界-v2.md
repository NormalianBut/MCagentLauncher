# MCagentlauncher 架构职责边界 v2

本文件用于防止后续实现中混淆 GitHub、Vercel、Supabase、MCAgent 和 Desktop 的职责。

---

## 1. 完整链路

```text
GitHub
  代码协作 / CI / Release
    ↓
Vercel
  官网 / 文档 / Web 控制台 / Preview
    ↓
Supabase
  社区数据 / Auth / 规则 / 别名 / 匿名案例
    ↓
MCAgent Inference Endpoint
  自然语言解析 / 资源规划 / 解释 / 诊断
    ↓
Desktop Local Executor
  本地实例 / 下载 / 校验 / 安装 / 启动 / 回滚
```

---

## 2. GitHub

### 做

- monorepo；
- Issue；
- PR；
- Actions；
- Release；
- 项目看板；
- 贡献讨论；
- 二进制产物发布。

### 不做

- 模型推理；
- 社区数据主存储；
- Minecraft 资源镜像；
- 用户本地文件操作。

---

## 3. Vercel

### 做

- apps/web；
- 官网；
- 文档；
- Roadmap；
- Web 控制台；
- 贡献入口；
- Preview Deployment；
- Supabase 数据展示前端。

### 不做

- GPU 推理；
- Minecraft 文件下载代理；
- 长时间安装任务；
- 用户本地文件操作；
- 桌面端核心逻辑。

---

## 4. Supabase

### 做

- Postgres；
- Auth；
- Storage；
- Edge Functions；
- community_aliases；
- resource_rules；
- anonymous_cases；
- model_eval_cases；
- community_nodes；
- 审核工作流。

### 不做

- GPU 推理；
- 资源镜像；
- 存储未脱敏完整日志；
- 操作用户本地实例；
- 保存 access token。

---

## 5. MCAgent Endpoint

### 做

- parse_intent；
- plan_resources；
- explain_plan；
- diagnose_log；
- repair_plan；
- 开源模型推理；
- RAG 检索；
- 自托管节点兼容。

### 不做

- 直接下载文件；
- 直接写入 mods 文件夹；
- 直接删除文件；
- 直接执行系统命令；
- 直接绕过规则引擎。

---

## 6. Desktop Local Executor

### 做

- 用户确认；
- 本地实例创建；
- Minecraft 安装；
- Fabric 安装；
- 下载资源；
- hash 校验；
- 写配置；
- 写 lockfile；
- 启动游戏；
- 捕获日志；
- 快照；
- 回滚。

### 不做

- 训练模型；
- 存储社区数据主库；
- 充当资源镜像；
- 默认上传隐私日志。

---

## 7. 数据流

### 创建实例

```text
User Prompt
    ↓
Desktop UI
    ↓
MCAgent /v1/intent/parse
    ↓
intent.json
    ↓
MCAgent /v1/resources/plan
    ↓
resource-plan.json
    ↓
Desktop Plan Review
    ↓
User Confirmation
    ↓
Desktop Local Executor
    ↓
instance-lock.json
```

### 社区贡献

```text
用户同意
    ↓
Desktop 本地脱敏
    ↓
上传预览
    ↓
Supabase anonymous_cases
    ↓
审核/统计/训练候选
```

### Web 控制台

```text
GitHub/Vercel Web
    ↓
Supabase Auth
    ↓
Supabase community tables
    ↓
审核规则/别名/节点
```

---

## 8. 禁止事项

1. 禁止 Vercel 承担长期模型推理核心。
2. 禁止 Supabase 存储未脱敏完整日志。
3. 禁止 MCAgent 返回可直接执行的 shell 命令。
4. 禁止 Desktop 默认信任 MCAgent 输出。
5. 禁止资源下载绕过原平台规则。
6. 禁止把用户数据默认上传。
7. 禁止把商业大模型作为 v0.1 必需运行条件。
