# MCagentlauncher v0.1 - Natural Instance 项目启动书 v2

版本：v0.2-draft  
日期：2026-07-08  
执行对象：Codex、项目维护者、早期贡献者  
核心链路：**GitHub–Vercel–Supabase–MCAgent–Desktop**

---

## 1. 启动书目标

本启动书用于指导 Codex 完成 MCagentlauncher v0.1 的可执行开发计划。

v0.1 目标：

> 用户输入一句自然语言需求，系统生成可审查的资源配置方案，并在用户确认后创建一个真实可启动的 Minecraft Fabric 实例。

---

## 2. 架构边界

本项目不是单纯的 GitHub–Vercel–Supabase 项目。

完整职责链路为：

```text
GitHub
    ↓
Vercel
    ↓
Supabase
    ↓
MCAgent Endpoint
    ↓
Desktop Local Executor
```

### 2.1 GitHub

用于：

- 代码；
- Issue；
- PR；
- CI；
- Release；
- 构建产物。

### 2.2 Vercel

用于：

- `apps/web`；
- 官网；
- 文档；
- Web 控制台；
- PR Preview；
- 贡献入口。

不得用于：

- 长期模型推理；
- Minecraft 资源下载代理；
- 用户本地执行。

### 2.3 Supabase

用于：

- 社区别名；
- 社区规则；
- 匿名案例；
- Auth；
- Storage；
- Edge Functions；
- 审核状态。

不得用于：

- GPU 推理；
- Minecraft 资源镜像；
- 未脱敏完整日志仓库。

### 2.4 MCAgent Endpoint

用于：

- 自然语言解析；
- 资源方案生成；
- 方案解释；
- 后续日志诊断；
- 后续修复计划。

必须独立可替换。

### 2.5 Desktop Local Executor

用于：

- 本地实例操作；
- 下载；
- hash 校验；
- Fabric 安装；
- 启动；
- 日志；
- 回滚。

这是唯一可以真实修改用户实例的组件。

```text
背景：
MCagentlauncher 是一个开源智能 Minecraft 启动器。它不是传统启动器 + AI 聊天框，而是自然语言驱动的实例生成系统。v0.1 目标是 Natural Instance：自然语言 → 资源方案 → 用户确认 → 本地执行 → 可启动实例。

涉及路径：
全部新仓库。

具体要求：
1. 创建 apps/desktop、apps/web、crates、services/mcagent-server、packages、supabase、datasets、docs、examples、.github。
2. 添加 README.md。
3. 添加 docs/vision.md、roadmap.md、architecture.md、privacy.md、security.md、contribution.md。
4. 添加 docs/platform-boundaries.md，明确：
   - GitHub = 协作/CI/Release
   - Vercel = Web/Docs/Console/Preview
   - Supabase = 社区数据/Auth/规则/别名/匿名案例
   - MCAgent = 独立推理 endpoint
   - Desktop = 本地执行器
5. 添加 LICENSE-DRAFT.md。
6. 添加 .gitignore。
7. 添加 GitHub Issue 模板。
8. 不实现复杂业务逻辑。

不得做：
1. 不要把模型推理写入 Vercel 作为长期架构。
2. 不要把 Supabase 当作资源镜像。
3. 不要让 MCAgent 执行本地文件操作。
4. 不要默认上传完整日志。
5. 不要接入商业大模型作为必要运行条件。
6. 不要写下载第三方资源文件的业务逻辑。

验收标准：
1. 仓库结构完整。
2. README 能解释项目定位。
3. docs 能解释架构边界。
4. 没有 secret。
5. 没有商业大模型强依赖。
6. 没有资源平台绕过逻辑。
7. 可以提交第一个 commit。
```

## 9. v0.1 Definition of Done

v0.1 完成时必须满足：

1. GitHub 项目可协作；
2. Vercel Web 可预览；
3. Supabase local 可启动；
4. MCAgent server 可独立运行；
5. Desktop app 可调用 MCAgent；
6. Schema 可校验；
7. intent 可生成；
8. plan 可生成；
9. Modrinth 资源可解析；
10. Fabric 资源可筛选；
11. 用户可审查 plan；
12. 本地执行器可创建实例；
13. 下载文件可 hash 校验；
14. instance-lock 可生成；
15. 可尝试启动 Minecraft；
16. AI 不直接执行；
17. Supabase 不保存未脱敏完整日志；
18. Vercel 不承担模型推理；
19. 不依赖商业大模型。
