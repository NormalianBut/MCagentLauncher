# v0.1 Alpha Release Candidate Checklist

## 1. Tag Verification

- [ ] `v0.1-alpha-preview` exists locally.
- [ ] `v0.1-alpha-preview` exists on `origin`.
- [ ] Tag points to the expected commit.
- [ ] GitHub Actions are green for the release candidate commit.

## 2. Build Verification

- [ ] `pnpm validate:schemas` passes.
- [ ] `pnpm test:shared-types` passes.
- [ ] `pnpm test:api-client` passes.
- [ ] `pnpm --dir apps/web build` passes.
- [ ] `pnpm --dir apps/desktop build` passes.
- [ ] `cd services/mcagent-server && python -m pytest -q` passes.

## 3. Manual Demo Verification

- [ ] MCAgent Server starts.
- [ ] Web/API Playground starts.
- [ ] Desktop Shell starts.
- [ ] Parse Intent works.
- [ ] Generate Plan works.
- [ ] Explain Plan works.
- [ ] Generate Install Preview works.
- [ ] Generate Environment Preview works.
- [ ] Run Safe Platform Probe works after consent.
- [ ] Confirm Install remains blocked as preview-only.

## 4. Safety Verification

- [ ] No real download.
- [ ] No real install.
- [ ] No local instance write.
- [ ] No Minecraft launch.
- [ ] No Java probe.
- [ ] No path scan.
- [ ] No disk scan.
- [ ] No environment report upload.
- [ ] No environment report persistence.
- [ ] No commercial model key.
- [ ] No secret, token, or API key.

## 5. Release Page Verification

- [ ] Release title is ready.
- [ ] Release body is ready.
- [ ] Known limitations are included.
- [ ] Safety boundaries are included.
- [ ] Demo guide is linked.
- [ ] No wording implies real installation or launch support.

## 6. Screenshot Verification

- [ ] Desktop overview screenshot manually reviewed.
- [ ] Web Playground screenshot manually reviewed.
- [ ] Install preview screenshot manually reviewed.
- [ ] Environment probe screenshot manually reviewed.
- [ ] Screenshots do not contain real user paths, emails, tokens, secrets, or private server data.

## 7. Release Decision

- [ ] Ready to create GitHub Release manually.
- [ ] Blocked pending fixes.
- [ ] Deferred to next candidate.
