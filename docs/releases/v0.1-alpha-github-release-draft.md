# MCagentlauncher v0.1 Alpha Preview - Natural Instance

## What This Release Is

MCagentlauncher v0.1 Alpha Preview is an early dry-run preview of a natural-language Minecraft instance planning workflow.

It does not install or launch Minecraft.

The current flow demonstrates:

```text
Natural language -> Intent -> Resource Plan -> Explanation -> Install dry-run -> Executor dry-run -> Environment preview
```

## Highlights

- Natural language intent parsing.
- Resource plan generation.
- Plan diagnostics.
- Plan explanation.
- Install action dry-run preview.
- Executor dry-run preview.
- Desktop Shell alpha UI.
- Web/API Playground.
- Environment preview.
- User-consented safe platform probe.

## What Works In This Release

- MCAgent mock/offline server can parse intent and generate resource plans.
- Resource plans are validated against JSON Schema.
- Plan responses include diagnostics such as `networkUsed`, warnings, errors, alias matches, resolver queries, and candidate counts.
- Web/API Playground can call the MCAgent planning APIs.
- Desktop Shell can run the preview flow and show human-readable summary cards plus raw JSON.
- Install action preview produces dry-run actions with `requiresUserConfirmation=true`.
- Executor dry-run preview reports `canExecute=false`.
- Environment preview produces local-only reports.
- Safe platform probe can read only OS, architecture, app version, and Tauri runtime availability after explicit user consent.

## What Does Not Work Yet

- No resource download.
- No Minecraft installation.
- No Fabric / Forge / NeoForge installation.
- No instance creation.
- No `mods` / `resourcepacks` / `shaderpacks` writing.
- No Minecraft launch.
- No Java detection.
- No Minecraft directory scan.
- No environment report upload.
- No commercial model integration.

## Safety Boundaries

- AI planning layer cannot execute files.
- MCAgent can plan and explain, but cannot write local files or run commands.
- Web Playground cannot access local files.
- Desktop Shell is dry-run only.
- Environment report is local-only.
- Safe platform probe only reads OS / arch / app version / Tauri availability.
- Desktop Local Executor is not enabled.
- User confirmation is required before any future executor can run.

## How To Try It Locally

```bash
pnpm install
pnpm dev:server
pnpm dev:web
pnpm dev:desktop
```

## Demo Flow

See `docs/demo/v0.1-alpha-demo-flow.md`.

Short version:

1. Start MCAgent Server.
2. Open Web/API Playground.
3. Open Desktop Shell.
4. Parse the default prompt.
5. Generate a resource plan.
6. Explain the plan.
7. Generate install preview.
8. Generate environment preview.
9. Run safe platform probe after consent.
10. Confirm that Install remains preview-only.

```bash
pnpm validate:schemas
pnpm test:shared-types
pnpm test:api-client
pnpm --dir apps/web build
pnpm --dir apps/desktop build
cd services/mcagent-server && python -m pytest -q
```

## Known Limitations

- Planning can still use mock/offline data.
- Offline mode does not verify the latest Modrinth metadata.
- Desktop is not packaged as an installer.
- No account/login integration exists.
- No real Desktop Local Executor exists.
- UI and messages are alpha quality.
