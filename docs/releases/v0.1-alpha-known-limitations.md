# v0.1 Alpha Known Limitations

## Functional Limitations

- Mock/offline planning still exists.
- Resolver may not fully validate latest resource metadata in offline mode.
- No real Minecraft instance creation.
- No resource download.
- No Fabric, Forge, or NeoForge installation.
- No Java detection.
- No game launch.
- No account/login integration.
- No CurseForge support.
- No real local executor.

## Safety Limitations

- Safe platform probe intentionally avoids Java, path, disk, and network checks.
- Environment report remains local-only.
- No environment report export or upload exists in v0.1 alpha.
- No persistence exists for environment reports.
- User-selected directory probing requires a future ADR.
- Real Java probing requires a future ADR.

## User Experience Limitations

- UI is alpha quality.
- Error messages may be technical.
- M12 can produce a Windows x64 unsigned preview installer for manual testing; it is not a stable release.
- Local development setup is required.
- Screenshots are not bundled in the release candidate materials yet.

## Contributor Limitations

- Some schema contracts may still evolve.
- Desktop executor contract is preview-only.
- macOS and Linux packaging, code signing, notarization, automatic updates, and sidecar lifecycle are not validated.
- Docs may move as the public website matures.

## Explicit Non-goals For This Alpha

- This alpha preview does not install or launch Minecraft.
- This alpha preview does not write local instances.
- This alpha preview does not download resources.
- This alpha preview does not upload environment reports.
