## Architecture Summary

The Planner creates `ResourceRequirement[]`. `MetadataResourceResolver` consults registered adapters in explicit provider order. `ModrinthMetadataProvider` performs only metadata queries, normalizes records into generic candidates, and returns structured issues. Resolver output remains metadata for plan review, not an installation instruction.

The Python MCAgent Server remains offline and continues to declare `liveResourceResolver=false`.

## Security Verification

- Offline policy performs no fetch.
- Metadata-only mode requests Modrinth API JSON endpoints only.
- CDN/resource URLs are not requested.
- Downloads, uploads, filesystem access, execution, and telemetry remain false in diagnostics.
- No Minecraft path, Java, shell, process, installer, launcher, token, secret, or paid AI integration was added.
- `docs/platform-boundaries.md` is unchanged.

## Limitations

- MCAgent Server does not call the TypeScript provider in M14.
- Live resolver capability remains false.
- No metadata cache or automatic retry policy exists.
- GitHub Releases and MC百科 providers remain contract-only.
- CurseForge remains future and unimplemented.
- File URLs and hashes are metadata claims only; no artifact is downloaded or verified locally.
