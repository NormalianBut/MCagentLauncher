# v0.1 Alpha Screenshot Checklist

This checklist is for manual screenshots only.

Do not generate screenshots automatically. Do not introduce Playwright or screenshot automation for this release candidate.

## Desktop Screenshots

- [ ] Desktop Shell overview.
- [ ] Prompt and flow stepper.
- [ ] Intent summary.
- [ ] Resource plan summary.
- [ ] Install preview summary.
- [ ] Executor dry-run preview.
- [ ] Environment preview.
- [ ] Safe platform probe result.
- [ ] Confirm Install blocked state.

## Web Screenshots

- [ ] API Playground overview.
- [ ] Intent parse result.
- [ ] Plan diagnostics.
- [ ] Explanation panel.

## Screenshot Safety Review

Before publishing screenshots, confirm:

- [ ] No real user path is visible.
- [ ] No home directory is visible.
- [ ] No `.minecraft` directory path is visible.
- [ ] No email address is visible.
- [ ] No token is visible.
- [ ] No secret is visible.
- [ ] No API key is visible.
- [ ] No private server address is visible.
- [ ] No environment report upload is shown or implied.
- [ ] No text implies real installation or Minecraft launch support.

## Notes

Screenshots will be added after manual UI review.
