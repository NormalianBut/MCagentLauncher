# v0.1 Alpha Feedback Guide

MCagentlauncher v0.1 Alpha Preview accepts structured feedback about the planning flow, Desktop Shell, Web Playground, runtime connection contract, and safety boundaries.

## Feedback Scope

Useful reports include:

- reproducible application bugs;
- Desktop or Web UI/UX problems;
- intent parsing or resource-plan mismatches;
- resource resolution metadata mismatches;
- Desktop-to-MCAgent connection and compatibility problems;
- safety boundary concerns or misleading execution claims.

The alpha does not download, install, write a Minecraft instance, detect Java, scan paths, or launch Minecraft. Requests for those features should be discussed as future architecture work, not reported as a regression in the alpha executor.

## Bug Categories

- MCAgent Server API or schema validation;
- Desktop connection status or compatibility gating;
- Web Playground planning flow;
- intent, plan, diagnostics, or explanation output;
- dry-run install/executor preview;
- consented safe platform probe;
- documentation or release materials.

## UI/UX Feedback

Describe the screen, action, expected interaction, actual interaction, viewport or platform, and any accessibility impact. Screenshots are useful only after removing personal paths, account names, notifications, tokens, and unrelated private content.

## Planning Mismatch

Provide a redacted prompt, Minecraft version, loader, expected mods/features, actual plan summary, `networkUsed`, and relevant warnings/errors. Do not include unrelated personal context in the prompt.

## Resource Resolution Mismatch

Identify the resource name, expected project or version, target Minecraft version and loader, observed candidate metadata, and whether the plan was offline. Do not attach downloaded binaries.

## Desktop Connection Problems

Include the configured endpoint with credentials and private host details removed, connection error code, server version if available, API/schema version if available, whether `/health` and `/v1/meta` respond, and concise reproduction steps.

## Security Boundary Concerns

Do not publish exploits, credentials, tokens, private paths, or sensitive environment data in a public issue. If GitHub private vulnerability reporting is visibly available for this repository, use it. Otherwise use a maintainer-published private security contact. This document does not claim that private reporting is enabled.

## Required Reproduction Information

- app component;
- version or tag;
- operating system family, without usernames or device identifiers;
- minimal reproduction steps;
- expected and actual results;
- relevant redacted warning/error text;
- safety impact, if any.

## Privacy Checklist

Before submitting, remove:

- tokens, secrets, API keys, cookies, and authorization headers;
- complete local paths, usernames, home directories, and IP addresses;
- full environment reports;
- unrelated logs or prompts;
- downloaded Minecraft or third-party resource files.

Prefer the smallest redacted log excerpt that proves the problem. MCagentlauncher does not automatically collect telemetry, upload logs, send environment reports, or connect feedback forms to Supabase.
