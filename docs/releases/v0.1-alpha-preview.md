# MCagentlauncher v0.1 Alpha Preview - Natural Instance

## Release Scope

This alpha preview demonstrates the v0.1 planning flow without enabling real local execution.

```text
Natural language -> Intent -> Resource Plan -> Explanation -> Install dry-run -> Executor dry-run -> Environment preview
```

## What Works Now

- Natural language intent parsing.
- Resource planning through the MCAgent mock/offline pipeline.
- Plan diagnostics with alias, resolver, warning, error, and `networkUsed` signals.
- Explanation generation for resource plans.
- Install action dry-run preview.
- Executor dry-run preview with `canExecute=false`.
- Desktop Shell preview UI.
- Web/API Playground.
- Environment preview.
- User-consented safe platform probe for OS, arch, app version, and Tauri runtime availability.

## What Does Not Work Yet

- Cannot download Minecraft or resource files.
- Cannot install Fabric, Forge, NeoForge, mods, resource packs, or shader packs.
- Cannot create real Minecraft instances.
- Cannot write `mods`, `resourcepacks`, or `shaderpacks`.
- Cannot launch Minecraft.
- Cannot detect Java.
- Cannot scan Minecraft directories or user paths.
- Cannot scan disks.
- Cannot upload environment reports.
- Cannot persist environment reports.

## Safety Boundaries

- AI does not execute files.
- MCAgent plans and explains; it does not write files or run commands.
- Web Playground cannot access local files.
- Desktop execution is disabled in this alpha preview.
- Environment reports are local-only and not uploaded.
- User confirmation is required before any future executor can run.

## How To Run

```bash
pnpm install
pnpm dev:server
pnpm dev:web
pnpm dev:desktop
```

## Demo Flow

1. Start MCAgent Server.
2. Open Web Playground.
3. Open Desktop Shell.
4. Parse the default prompt.
5. Generate a resource plan.
6. Explain the plan.
7. Generate install preview.
8. Generate environment preview.
9. Run safe platform probe after consent.
10. Click Confirm Install and verify it is preview-only.

Expected preview indicators:

- `networkUsed=false`
- `dryRun=true`
- `canExecute=false`
- `localOnly=true`
- `uploadAllowed=false`
- `filesWritten=0`
- `networkRequests=0`

## Known Limitations

- Resource planning can use mock/offline data.
- Modrinth metadata resolution is not enabled by default in the MCAgent Server.
- Desktop native packaging is not part of this alpha preview.
- Environment probing is limited to safe platform metadata only.
- Install actions are audit previews, not executable plans.
