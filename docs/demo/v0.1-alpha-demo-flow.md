# v0.1 Alpha Demo Flow

This guide demonstrates the MCagentlauncher v0.1 alpha preview. It is a dry-run preview only.

Screenshots will be added after manual UI review.

## 1. Prepare Environment

Install dependencies from the repository root:

```bash
pnpm install
```

## 2. Start MCAgent Server

```bash
pnpm dev:server
```

Expected result:

- `GET /health` returns `status=ok`.
- Server remains offline by default for resource planning.

## 3. Start Web Playground

```bash
pnpm dev:web
```

Open the printed localhost URL.

Expected result:

- Page title is `MCagentlauncher v0.1 - Natural Instance API Playground`.
- Safety banner says Web cannot access local files or install Minecraft.

## 4. Start Desktop Shell

```bash
pnpm dev:desktop
```

Open the printed Vite URL.

Expected result:

- Header says `v0.1 - Natural Instance Alpha Preview`.
- Safety banner says no download, no install, no local write, and no Minecraft launch.

## 5. Use Default Prompt

Default prompt:

```text
我想玩 1.20.1，低配光影生存，要优化、小地图、苹果皮，别太复杂。
```

## 6. Parse Intent

Click `Parse Intent`.

Expected result:

- Intent summary shows Minecraft `1.20.1`.
- Loader defaults to Fabric.
- Goals include performance, shader, survival, and minimap.
- Raw JSON remains available.

## 7. Generate Plan

Click `Generate Plan`.

Expected result:

- Plan summary shows resource count and required resource count.
- Diagnostics show `networkUsed=false`.
- Warnings/errors are visible if present.

## 8. Explain Plan

Click `Explain Plan`.

Expected result:

- Explanation JSON is shown.
- Explanation describes why resources are recommended.
- Explanation does not claim anything was installed.

## 9. Generate Install Preview

Click `Generate Install Preview`.

Expected result:

- Install summary shows `dryRun=true`.
- Executor summary shows `canExecute=false`.
- Action groups are visible for instance, Minecraft/loader, resources, config, snapshot, and launch preview.

## 10. Generate Environment Preview

Click `Generate Environment Preview`.

Expected result:

- Environment report is local-only.
- `uploadAllowed=false`.
- `filesWritten=0`.
- `networkRequests=0`.

## 11. Run Safe Platform Probe

Click `Run Safe Platform Probe`, then confirm the consent modal.

Expected result:

- Probe reads only OS, arch, app version, and Tauri runtime availability.
- Java is not checked by M8.3 policy.
- Minecraft path is not checked by M8.3 policy.
- Disk is not checked by M8.3 policy.
- Network is not checked by M8.3 policy.

## 12. Confirm Install Blocked

Click `Confirm Install (preview-only)`.

Expected result:

- UI says v0.1 alpha supports dry-run preview only.
- No Desktop Local Executor is enabled.

## 13. No Real Execution Checklist

During the demo, confirm:

- `networkUsed=false`
- `dryRun=true`
- `canExecute=false`
- `localOnly=true`
- `uploadAllowed=false`
- `filesWritten=0`
- `networkRequests=0`

The demo must not create files, download resources, install Minecraft, write a local instance, or launch Minecraft.
