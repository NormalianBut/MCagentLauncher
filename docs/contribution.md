# Contribution

MCagentlauncher is intended to be community-built.

Useful contribution areas include:

- schemas and examples
- rule definitions
- alias mappings
- documentation
- Desktop UX
- MCAgent endpoint behavior
- Supabase community workflows
- Web console and docs

## Contribution Rules

- Respect the platform boundaries in `docs/platform-boundaries.md`.
- Do not add commercial large model dependencies as required runtime behavior.
- Do not add resource mirroring or platform bypass logic.
- Do not commit secrets.
- Do not add local execution behavior outside the Desktop Local Executor.
- Keep plans and generated files auditable.

## Review Expectations

Pull requests should explain what changed, which layer owns the change, what was tested, and whether privacy, security, or resource verification behavior is affected.
