# Vision

MCagentlauncher aims to make "describe what I want to play" a practical entry point for creating Minecraft instances.

The project should turn natural language into auditable configuration plans, use deterministic rules and verified metadata to reduce mistakes, and preserve user control before any installation happens.

Long term, MCagentlauncher should become a community-built MCAgent ecosystem: open schemas, open rules, shared aliases, anonymized cases, replaceable inference endpoints, and self-hostable nodes.

## Non-Goals

- It is not a Minecraft resource mirror.
- It is not a commercial model wrapper.
- It is not a Web-only launcher.
- It does not let AI directly modify local files.
